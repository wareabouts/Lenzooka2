# Lenzooka prompt package

Hand this whole folder to Claude Code or Codex as the starting contents of the `wareabouts/lenzooka` repo, then say:

"Read PROMPT.md and build it. docs/, data/ and the photos are inputs, keep them in the repo."

Contents:
- PROMPT.md        the build spec
- data/lens.json   seed model (compartments, objects, pins, photos, three open view requests from Claude). Poses are rough; fix them in edit mode.
- docs/conventions.md, docs/register.md   the naming vocabulary and the current state of knowledge
- docs/photos/     13 downscaled reference photos, named by their six-digit IDs
